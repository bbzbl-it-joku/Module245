# UI style guide

## Goal
Keep the sign-in and app views visually consistent with the landing page by sharing the same light palette, background treatment, and glass card surfaces.

## Palette
- Base background: soft amber to slate to emerald gradient.
- Accents: emerald for primary actions, slate for secondary actions.
- Surfaces: white at 60-80% opacity with soft borders and subtle shadows.

## Layout
- Use the landing background blobs and gradient on top-level pages.
- Apply a translucent header with a light border and blur.
- Keep content in a centered max-width container with generous vertical spacing.

## Components
- Component library: shadcn/ui.
- Shared primitives live in components/ui.
- Current primitives used: Button, Input.

## Page alignment
- Sign-in page and app page mirror the landing background, header style, and card treatments.
- Dark mode styles are intentionally removed to keep the palette unified.
